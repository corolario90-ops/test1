# 포켓몬 한글 모험

다섯 살 아이가 아이패드와 애플펜슬로 한글을 배우며 포켓몬을 모으는 게임이에요.
8개 마을(체육관 배지 8개)을 차례로 지나며 소리 찾기, 글자 만들기, 따라 쓰기, 읽고 고르기, 받아쓰기, 체육관 배틀을 해요.

## 아이패드에 설치하기

1. 아이패드 **사파리**에서 https://corolario90-ops.github.io/test1/ 을 열어요.
2. 주소창 옆 **공유** 버튼 → **홈 화면에 추가** → **추가**.
3. 홈 화면의 "포켓몬 한글" 아이콘으로 열면 주소창 없이 전체 화면으로 열려요. 한 번 열고 나면 인터넷이 없어도 돼요.

## 파일

- `app-src.html` — 화면과 게임 코드
- `ink.js` — 따라 쓰기·받아쓰기 채점
- `build.py` — 위 두 파일을 합쳐서 `pwa/`(홈 화면 앱)와 `pokemon-hangul.html`(Claude 링크용)을 만듦
- `sw-template.js` — 인터넷 없이 열리게 하는 서비스 워커 원본
- `icon.js` — 앱 아이콘 만들기 (Playwright)
- `pwa/` — 실제로 배포되는 앱. `gh-pages` 브랜치에 이 폴더 내용이 그대로 올라가요.

## 고친 뒤 다시 배포하기

```sh
python3 pokemon-hangul/build.py
# pokemon-hangul/pwa/ 내용을 gh-pages 브랜치 맨 위에 복사해서 커밋·푸시
```

배포할 때마다 `sw.js`의 캐시 이름이 바뀌어서, 아이패드에서 인터넷이 될 때 앱을 열면 새 버전으로 바뀌어요.
