# 몬스터 숫자 놀이

아이패드로 더하기·빼기, 곱하기, 시계 읽기, 세는 말을 익히며 포켓몬을 모으는 게임이에요.
한 번에 맞히면 포켓몬을 잡아 도감을 채워요.

## 아이패드에 설치하기

1. 아이패드 **사파리**에서 https://corolario90-ops.github.io/test1/math/ 을 열어요.
2. 주소창 옆 **공유** 버튼 → **홈 화면에 추가** → **추가**.
3. 홈 화면의 "몬스터 숫자" 아이콘으로 열면 주소창 없이 전체 화면으로 열려요. 한 번 열고 나면 인터넷이 없어도 돼요.

공식 이미지는 기본으로 꺼져 있어요. 홈 화면의 **그림** 칸에서 켤 수 있고, 켠 뒤 '그림 미리 받기'를 누르면 인터넷 없이도 보여요.

## 파일

- `app-src.html`: 화면과 게임 코드
- `mon-art.js`: 직접 그린 포켓몬 그림 (몬스터 한글 모험과 같은 그림)
- `build.py`: 위 두 파일을 합쳐서 `pwa/`(홈 화면 앱)와 `pokemon-math.html`(Claude 링크용)을 만듦
- `sw-template.js`: 인터넷 없이 열리게 하는 서비스 워커 원본
- `icon.js`: 앱 아이콘 만들기 (Playwright)
- `pwa/`: 실제로 배포되는 앱. `gh-pages` 브랜치의 `math/` 폴더에 이 폴더 내용이 그대로 올라가요.

## 고친 뒤 다시 배포하기

```sh
python3 pokemon-math/build.py
# pokemon-math/pwa/ 내용을 gh-pages 브랜치의 math/ 폴더에 복사해서 커밋·푸시
```

배포할 때마다 `sw.js`의 캐시 이름이 바뀌어서, 아이패드에서 인터넷이 될 때 앱을 열면 새 버전으로 바뀌어요.
몬스터 한글 모험(사이트 맨 위)의 서비스 워커는 `math/` 아래 요청을 건드리지 않도록 되어 있어요.
