24시간 켜 두는 방법

  1. 크롬에서 이 화면을 연 다음 메뉴(⋮) → 홈 화면에 추가를 누르세요. 홈 화면 아이콘으로 열면 주소창 없이 전체 화면으로 떠요.
  2. 충전기를 꽂아 두면, 이 앱이 화면에 떠 있는 동안 화면이 꺼지지 않아요. 충전기를 빼면 평소처럼 꺼져서 배터리를 아껴요.
  3. 더 확실하게 하려면 태블릿 설정 → 태블릿 정보 → 소프트웨어 정보 → 빌드 번호를 7번 눌러 개발자 옵션을 켠 뒤, 설정 → 개발자 옵션 → 화면 켜짐 상태 유지를 켜 주세요. 충전하는 동안은 태블릿이 스스로 화면을 끄지 않아요.
  4. 다른 앱을 열었다 돌아오거나 태블릿을 다시 켜면 이 앱 아이콘만 누르면 돼요. 사진과 설정은 그대로 남아 있어요.
  5. 하루 종일 같은 자리에 글자가 떠 있으면 화면에 잔상이 남을 수 있어서, 글자 위치를 몇 분마다 아주 조금씩 옮기고 있어요. 밤에는 야간 모드를 켜 두면 더 좋아요.
